# WalletWatcher

I developed my first webapp. 
It is a simple budget tracking webapp where anyone can easily track their income and expenses.

I have used Vite React, Express & MongoDB for developing.
I have used Render, Vercel and Cloudinary for deployment and storage.

### Check it out here: 
https://wallet-watcher-theta.vercel.app/

### Features
##### User Signup & Login
- Upload Image
- Name
- Email
- Password
- Edit Profile (Name, Profile Photo)

##### Dashboard
- Total Balance
- Total Income
- Total Expense
- Recent Transactions
- Financial Overview: A pie chart of income and expenses with total balance
- Expense List
- Last 30 Days Expenses in Bar Chart
- Income List
- Last 30 Days Income in Pie Chart

##### Expenses
- Add Expense
- Graph of expenses
- Expense List
- Download expenses in excel format

##### Income
- Add Income
- Income Overview in Bar Grah
- Income List
- Download income in excel format

### Tech Stack

##### Development
**Frontend:** React(Vite)
**Backend:** Node.js, Express
**Database:** MongoDB

##### Deployment
**Frontend:** Vercel
**Backend:** Render
**Storage:** Cloudinary
